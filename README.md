# 🍱 快餐订餐系统（Canteen Order System）

一个用纯 Python 标准库写成的命令行点餐系统。支持多店铺菜单、点菜下单、订单合并统计、总价计算，并把每一单持久化到本地 JSON 文件、随时查看历史订单。

> 这是我的Python计算课程作业。代码里保留了较多中文注释，既是给使用者看的，也是给正在学 Python 的自己看的。

## ✨ 功能特性

- **多店铺菜单**：内置「早餐铺 / 面馆 / 默认菜单」，用字典派发选择，输入其他店名自动用默认菜单。
- **交互式点菜**：按编号选菜，可重复点同一道菜，输入校验友好。
- **订单合并**：用 `Counter` 把同款菜合并成「菜名 × 数量」，并算出小计与合计。
- **订单持久化**：每次下单自动写入 `orders.json`，程序重开也不丢。
- **历史订单**：随时查看所有历史订单（时间 / 店铺 / 顾客 / 明细 / 合计）。

## 🚀 快速开始

需要 Python 3.10 及以上（用到了 `dict[str, float]` 这类新版类型注解写法）。无需安装任何第三方库。

```bash
git clone <你的仓库地址>
cd canteen-order-system
python food_canteen.py
```

运行后按提示操作：

```
========== 快餐订餐系统 ==========
请输入商户名称（早餐铺 / 面馆 / 其他）：面馆
请输入顾客姓名：兜兜猫

----------- 功能菜单 -----------
1. 执行下单    2. 查看本次订单    3. 查看历史订单    4. 退出
请输入操作编号：1
```
